# 📝 Modern To-Do List Application

A sleek, responsive, and minimalist To-Do List web application built from scratch to strengthen foundational front-end web development skills (HTML5, CSS3, and JavaScript). 

This project is part of my continuous learning journey in web development and software engineering practice.

---

## ✨ Features

* **Dynamic Task Management:** Add new tasks instantly and delete them dynamically without refreshing the page.
* **Modern Dark Theme:** Styled with a professional developer-inspired dark color palette (`#0f172a` slate theme) to ensure a clean visual aesthetic.
* **Interactive UI/UX:** Features smooth transitions, focus states, and the modern Inter typography font.
* **Separation of Concerns:** Cleanly organized into modular architecture (`todolist.html`, `todolist.css`, and `todolist.js`).

---

## 🛠️ Tech Stack

* **HTML5** – Semantic markup and DOM structure
* **CSS3** – Modern layouts (Flexbox), custom styling, and variable theming
* **JavaScript (ES6)** – DOM manipulation, event listeners, and dynamic element creation

---

## 💡 What I Learned Building This Project

* **DOM Manipulation:** Gained hands-on experience using JavaScript to create (`document.createElement`), append, and remove elements dynamically.
* **Event Handling:** Utilized event objects (`event.target.parentElement`) to manage user actions like deleting specific list items.
* **Modular Code Structure:** Learned the best practice of separating structure (HTML), styling (CSS), and behavior (JavaScript) into individual files for better maintainability.
